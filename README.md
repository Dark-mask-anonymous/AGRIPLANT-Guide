# AgriPlant Guide – A Simple Crop Planting Guide Web Application

## Domain
Agriculture

## Problem Identified
Many beginner farmers and home gardeners do not know the correct way to plant crops or the proper season for planting. Because of this, crops sometimes fail to grow properly or produce low harvests.

In addition, information about crop planting is often scattered across different websites and may be difficult for beginners to understand. Farmers and gardeners need a simple and organized guide that provides basic planting information in one place.

## Proposed Solution
AgriPlant Guide is a web-based application that provides simple, easy-to-understand crop planting information. The website allows users to view crop planting guides, search for different crops, see planting season and harvest time, and add simple planting reminders. This helps farmers, gardeners, and students learn proper planting practices and manage planting schedules more easily.

## Target Users
- Farmers
- Home gardeners
- Agriculture students
- Beginners who want to learn planting
- People interested in growing crops

## Features of the System
1. Crop Planting Guide: Users can view crop information including planting season, water requirements, sunlight needs, and harvest time.
2. Crop Search Feature (JavaScript): Users can search for crops by typing the crop name, such as searching "Tomato" to show the tomato guide.
3. Crop Information Cards: Each crop is displayed in a card layout containing the crop image, crop name, a short planting guide, and harvest information.
4. Planting Reminder (JavaScript + LocalStorage): Users can add planting reminders (for example, "Plant Tomatoes – March 20") and save them in the browser.
5. Dark Mode / Theme Switcher (JavaScript): Users can switch between light mode and dark mode to improve usability and accessibility.

## Minimum Pages / Sections
1. Home Page: Introduction to AgriPlant Guide, navigation menu, and featured crops.
2. Crop Guide Page: Crop cards for tomato, carrot, rice, and corn with planting information.
3. Reminder Page: Add reminders, view the reminder list, and delete reminders.

## JavaScript Interactive Features
1. Crop search function.
2. Planting reminder add/delete using LocalStorage.
3. Dark mode theme switcher.

Optional extras include modal popups for crop details and dynamic crop card display.

## Tools / Technologies Used
Front-end development uses HTML for structure, CSS for design and layout, and JavaScript for interactivity and logic.
